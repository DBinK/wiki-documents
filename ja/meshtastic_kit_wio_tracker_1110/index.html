Meshtastic® キットの使い方

note

この文書は AI によって翻訳されています。内容に不正確な点や改善すべき点がございましたら、文書下部のコメント欄または以下の Issue ページにてご報告ください。
https://github.com/Seeed-Studio/wiki-documents/issues

はじめに​

今すぐ購入 🖱️

Wio Tracker 1110 Dev Board（Nordic nRF52840 をベースとした BLE、Semtech LR1110 をベースとした LoRa）、Grove Air530 GPS モジュール、Grove 0.96" OLED ディスプレイ を搭載し、Meshtastic ファームウェアとネイティブに互換性があります。この開発キットは、低消費電力の Meshtastic トラッカー デバイスを構築するためのプラグアンドプレイのソリューションです。

特徴​

  • 簡単なセットアップ: ファームウェアをフラッシュするだけで、Meshtastic ネットワークの強力な機能を体験できます。
  • リアルタイム位置情報: 高精度 GPS 位置情報をサポートする GPS (Air530) モジュールを搭載。
  • 情報表示: Grove - OLED Display 0.96" スクリーンを搭載し、リアルタイムデータを明確に可視化。
  • 拡張性の高いインターフェース: Grove エコシステムと互換性があり、センサーやモジュールの簡単な拡張が可能。
  • オープンソースのハードウェアとソフトウェア: 二次開発やカスタマイズをサポートし、豊富な開発リソースと Meshtastic コミュニティのサポートを提供。

はじめに​

ハードウェア接続​

Grove-GPS モジュールをUARTポートに接続し、Grove-OLED ディスプレイをI2Cポートに接続します。

ボードの電源をオンにします。

設定​

デバイス接続​

接続タイプに応じて、最適なクライアントを選択してください。

  • IOS アプリ
  • Android アプリ
  • Web クライアント
  • CLI

  • Meshtasticアプリをダウンロードします。

  • Bluetooth パネルでターゲットデバイスを選択します。

  • ディスプレイに名前と PIN コードが表示されます。

  • コードを入力し、ペアリングをクリックしてデバイスを接続します。

  • Meshtasticアプリをダウンロードします。

  • +をクリックしてターゲットデバイスを選択します。

  • ディスプレイに名前と PIN コードが表示されます。

  • コードを入力し、OKをクリックしてデバイスを接続します。

Web クライアントを開き、新しい接続をクリックします。

  • Bluetooth 経由で接続

PC の Bluetooth を有効にし、Bluetoothタブを選択して新しいデバイスを接続します。

デバイスを選択し、ディスプレイに表示される PIN コードを入力してデバイスを接続します。

  • シリアル経由で接続

ボードを PC に接続し、Serialタブを選択して新しいデバイスを接続します。

ポートを確認するには以下を使用します：

ls /dev/cu.*

このライブラリは、Meshtasticノードのユーザー設定を管理するためのコマンドラインインターフェイス（CLI）を提供し、メッシュラジオを介してメッセージを送受信するための簡単な API を提供します。

パラメーター設定​

メッシュ通信を開始するには、地域を設定する必要があります。この設定はデバイスが使用する周波数範囲を制御し、地域に応じて設定する必要があります。

  • IOS アプリ
  • Android アプリ
  • Web クライアント
  • CLI

以下のコマンドを実行し、REGION-CODEを地域に応じたコードに置き換えてください。

meshtastic --set lora.region <REGION-CODE>

EU_433およびEU_868は、1時間あたりのデューティサイクル制限10%を遵守する必要があります。この制限は、1時間のローリングベースで毎分計算されます。制限に達すると、許可されるまでデバイスは送信を停止します。

これでデバイスのLoRaリージョンを設定したので、必要に応じて追加の設定を行い、ニーズに合わせて調整することができます。
