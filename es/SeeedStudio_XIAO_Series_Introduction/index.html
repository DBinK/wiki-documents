Seeed Studio XIAO INTRODUCCIÓN




La serie Seeed Studio XIAO es una colección de microcontroladores (MCUs) del tamaño de un pulgar, potentes y diseñados a medida para proyectos con limitaciones de espacio que requieren alto rendimiento y conectividad inalámbrica. Encarnando la esencia de plataformas de hardware populares como ESP32, RP2350, RP2040, nRF52840 y SAMD21, la serie XIAO compatible con Arduino es el conjunto de herramientas perfecto para que adoptes el tiny machine learning (TinyML) en el Edge.
