Flashear Jetson Linux

Selecciona tu producto y la versión de Jetson Linux que deseas flashear. Esta página actualmente incluye un subconjunto de los productos.

Preview
reComputer Super J4012
R36.4.3 (JetPack 6.2🚀)
Interfaz de hardware
Consulte aquí el uso de la interfaz de la carrier board: uso de la interfaz

note

JetPack con 🚀 soporta configuraciones MAXN super

Haz clic aquí para ver el soporte de Jetson Linux para tu dispositivo

1. Descargar​

Enlace

OneDrive1

Archivo

SHA256

CF37D028D6466DCC13201367E6358A69B7B5305CAE2A2B785E3ECFD3D8C66304

(Opcional) Verificar sha256​

Para verificar el hash SHA256 del archivo descargado, ejecute en la terminal:

sha256sum mfi_xxxx.tar.gz 
# Por ejemplo:
# sha256sum mfi_recomputer-super-orin-nx-16g-j401-6.2-36.4.3-2025-05-22.tar

Si el resultado coincide con el SHA256 indicado en la documentación, se confirma que el firmware descargado está completo e intacto.

2. Preparar requisitos​

  • Equipo anfitrión con Ubuntu
  • reComputer Super J4012 / J4011 / J3010 o J3011
  • Cable de datos USB Type-C
Recomendación para el host
Recomendamos usar un host físico con Ubuntu en lugar de máquinas virtuales.
Consulte la siguiente tabla para preparar el equipo anfitrión.

Versión de JetPackVersión de Ubuntu (Host)
18.0420.0422.04
JetPack 6.x✅✅

3. Entrar en modo Recovery​

Antes de pasar al siguiente paso, asegúrese de que la placa esté en modo de recuperación forzada.
Haga clic en "Paso a paso" para ver cómo entrar en modo de recuperación.
Paso a paso
  • Paso 1. Cambie el interruptor a la posición RESET.
  • Paso 2. Encienda la carrier board conectando el cable de alimentación.
  • Paso 3. Conecte la placa al PC con Ubuntu mediante un cable de datos USB Type-C.
  • Paso 4. En el PC con Linux, abra una terminal y ejecute lsusb. Si aparece una de las salidas siguientes según su SoM de Jetson, la placa está en modo de recuperación forzada.

Si el dispositivo no es detectado, pruebe:

  • Reconectar el cable USB.
  • Usar otro puerto USB (preferiblemente USB 2.0).
  • Asegurarse de que el dispositivo esté en modo de recuperación (mantener Recovery + Reset).

Tras entrar en modo de recuperación, abra una terminal en el PC con Linux y ejecute:

lsusb

Si la salida incluye alguno de los siguientes ID, la placa está en modo de recuperación forzada:

  • Para Orin NX 16GB: 0955:7323 NVidia Corp
  • Para Orin NX 8GB: 0955:7423 NVidia Corp
  • Para Orin Nano 8GB: 0955:7523 NVidia Corp
  • Para Orin Nano 4GB: 0955:7623 NVidia Corp

4. Instalar dependencias de flash​

Instalar las dependencias de flash en el PC Host:

sudo apt-get update && \
sudo apt-get install -y abootimg \
                        binfmt-support \
                        binutils \
                        cpp \
                        device-tree-compiler \
                        dosfstools \
                        lbzip2 \
                        libxml2-utils \
                        nfs-kernel-server \
                        python3-yaml \
                        qemu-user-static \
                        sshpass \
                        udev \
                        uuid-runtime \
                        whois \
                        openssl \
                        cpio \
                        rsync \
                        zstd

Adicionalmente, para Ubuntu 18.04 e inferiores, instalar lz4c

sudo apt-get install -y liblz4-tool

Para Ubuntu 20.04 / 22.04 y superiores:

sudo apt-get install -y lz4

5. Extraer y Flashear​

Paso 1: En el PC con Ubuntu, extraiga la imagen descargada:

cd <ruta-a-la-imagen>
sudo tar xpf  mfi_xxxx.tar.gz
# Por ejemplo:
# sudo tar xpf mfi_recomputer-super-orin-nx-16g-j401-6.2-36.4.3-2025-05-22.tar

Paso 2: Ejecute el siguiente comando para flashear JetPack en el NVMe SSD:

cd mfi_xxxx
# Por ejemplo:
# cd mfi_recomputer-orin-super-j401
sudo ./tools/kernel_flash/l4t_initrd_flash.sh --flash-only --massflash 1 --network usb0 --showlogs

Si el proceso de flasheo finaliza correctamente, verá una salida similar a la siguiente:

El comando de flasheo puede tardar entre 2 y 10 minutos.

Paso 3: Conecte el Jetson a un monitor mediante el conector HDMI de la placa y complete la configuración inicial:

Complete la configuración inicial del sistema según sus necesidades.

Paso 4 (opcional): Instalar NVIDIA JetPack SDK

Abra la terminal en el dispositivo Jetson y ejecute los siguientes comandos:

sudo apt update
sudo apt install nvidia-jetpack
