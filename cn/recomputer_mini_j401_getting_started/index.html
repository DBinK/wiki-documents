将 JetPack 刷入 J401-Mini 承载板

note

本文档由 AI 翻译。如您发现内容有误或有改进建议，欢迎通过页面下方的评论区，或在以下 Issue 页面中告诉我们：https://github.com/Seeed-Studio/wiki-documents/issues

reComputer Mini 是一款由 NVIDIA Jetson Orin Nano/Orin NX 模块驱动的小型 AI 计算机，提供高达 100 TOPS 的 AI 性能。它底部配备 PCIe 接口，提供丰富的扩展能力，同时支持灵活定制。整个系统设计用于嵌入无人机、巡逻机器人、配送机器人等自主机器中。它可以直接支持 54V DC 输入，广泛适用于电池供电系统。

立即获取 🖱️

特性​

  • 卓越的生产级 AI 性能： 通过 NVIDIA Orin SoC 实现高达 100 TOPS 的 AI 性能，结合 NVIDIA Ampere™ GPU 架构、64 位操作能力、集成的高级多功能视频和图像处理以及 NVIDIA 深度学习加速器。
  • 手掌大小的边缘 AI 设备： 紧凑尺寸为 63mmx95mmx42mm，配备 NVIDIA Jetson Orin NX 16GB 模块、Mini J401 承载板、风扇和外壳。支持桌面和壁挂安装。
  • 丰富的 I/O 扩展能力： 包括多达 7 个 USB 接口、1 个 DP 2.1、2 个 CSI、1 个 RJ45 千兆以太网、M.2 Key E、M.2 Key M、双通道 CAN 和 GPIO（通过扩展板）。
  • 加速解决方案上市： 预装 JetPack 6.0 于 128GB NVMe SSD，支持 Linux OS BSP、Jetson 软件和主流 AI 框架。
  • 规模化部署： 支持 OTA 和由 Allxon 和 Balena 提供的远程管理服务。
  • 灵活定制： 包括更换配件模块、定制 Logo 和基于 reComputer Mini J4012 原始设计修改硬件接口。

硬件概览​

刷写 JetPack 操作系统​

在这里，我们将向您展示如何将 Jetpack 6.0 刷写到连接到 reComputer Mini 的 NVMe SSD 上。

支持的 Nvidia Jetson 模块​

  • NVIDIA® Jetson Orin™ Nano 模块 4GB
  • NVIDIA® Jetson Orin™ Nano 模块 8GB
  • NVIDIA® Jetson Orin™ NX 模块 8GB
  • NVIDIA® Jetson Orin™ NX 模块 16GB

前置条件​

  • Ubuntu 主机电脑
  • 搭载 Jetson Orin 模块的 reComputer J401-Mini 扩展板
  • USB Micro-B 数据传输线
info

我们建议您使用物理 Ubuntu 主机设备，而不是虚拟机。 请参考下表准备主机设备。

进入强制恢复模式​

info

在进行安装步骤之前，我们需要确保开发板处于强制恢复模式。

分步操作
  • 步骤 1. 使用 USB Micro-B 数据线连接 USB2.0 DEVICE 端口和 Ubuntu 主机。
  • 步骤 2. 使用针插入 RECOVERY 孔并按住恢复按钮，同时保持按住。
  • 步骤 3. 连接电源。
  • 步骤 4. 松开恢复按钮。

在 Linux 主机上，打开终端窗口并输入命令 lsusb。如果返回的内容包含以下输出之一（根据您使用的 Jetson SoM），则说明开发板已进入强制恢复模式。

  • 对于 Orin NX 16GB: 0955:7323 NVidia Corp
  • 对于 Orin NX 8GB: 0955:7423 NVidia Corp
  • 对于 Orin Nano 8GB: 0955:7523 NVidia Corp
  • 对于 Orin Nano 4GB: 0955:7623 NVidia Corp

使用单条命令刷写到 Jetson​

使用单条命令刷写设备

reComputer Jetson J30/40 Mini 提供了一键刷写脚本，支持刷写 Jetpack 6.0。

wget -O ./flashing.sh https://files.seeedstudio.com/OSHW_Jetson/flashing.sh  && sudo chmod 777 ./flashing.sh && ./flashing.sh
caution

免责声明：一键刷写脚本旨在加快 Jetpack 的刷写过程。目前版本为测试版，可能存在许多问题。希望您能理解。如果遇到刷写问题，请按照下面的 分步刷写设备 进行操作，并在我们的 Discord Jetson 频道 中反馈问题。我们会及时修复并改进此功能。

分步刷写到 Jetson​

步骤 1: 在 Ubuntu 主机上解压下载的镜像文件：

cd <path-to-image>
sudo tar xpf mfi_xxxx.tar.gz
# 示例: sudo tar xpf mfi_recomputer-orin-nano-8g-j401-6.0-36.3.0-2024-06-07.tar.gz

步骤 2: 执行以下命令，将 Jetpack 系统刷写到 NVMe SSD：

cd mfi_xxxx
# 示例: cd mfi_recomputer-orin-j401
sudo ./tools/kernel_flash/l4t_initrd_flash.sh --flash-only --massflash 1 --network usb0  --showlogs

步骤 4（可选）: 安装 Nvidia Jetpack SDK

请在 Jetson 设备上打开终端并执行以下命令：

sudo apt update
sudo apt install nvidia-jetpack
