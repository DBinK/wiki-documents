刷写 Jetson Linux

选择您的产品和希望刷写的 Jetson Linux。此页面目前包含产品的子集。

Preview
reComputer Super J4012
R36.4.3 (JetPack 6.2🚀)
硬件接口
在此查看载板接口使用方法。 接口使用方法。

note

支持 🚀 MAXN super 配置的 JetPack

点击这里查看您设备的 Jetson Linux 支持情况

1. 下载​

链接

OneDrive1

文件

mfi_recomputer-super-orin-nx-16g-j401-6.2-36.4.3-2025-05-22.tar

SHA256

CF37D028D6466DCC13201367E6358A69B7B5305CAE2A2B785E3ECFD3D8C66304

（可选）验证 sha256​

要验证下载文件的SHA256哈希值，请在终端中运行：

sha256sum mfi_xxxx.tar.gz 
# 例如:
# sha256sum mfi_recomputer-super-orin-nx-16g-j401-6.2-36.4.3-2025-05-22.tar

如果结果哈希值与wiki中提供的SHA256哈希值匹配，则确认您下载的固件是完整且完好的。

2. 准备要求​

  • Ubuntu主机电脑
  • reComputer Super J4012 / J4011 / J3010 或 J3011
  • USB Type-C数据传输线
主机建议
我们建议您使用物理Ubuntu主机设备而不是虚拟机。
请参考下表准备主机设备。

JetPack版本Ubuntu版本（主机电脑）
18.0420.0422.04
JetPack 6.x✅✅

3. 安装刷写依赖​

在主机 PC 上安装刷写依赖：

sudo apt-get update && \
sudo apt-get install -y abootimg \
                        binfmt-support \
                        binutils \
                        cpp \
                        device-tree-compiler \
                        dosfstools \
                        lbzip2 \
                        libxml2-utils \
                        nfs-kernel-server \
                        python3-yaml \
                        qemu-user-static \
                        sshpass \
                        udev \
                        uuid-runtime \
                        whois \
                        openssl \
                        cpio \
                        rsync \
                        zstd

此外，对于 Ubuntu 18.04 及以下版本，安装 lz4c

sudo apt-get install -y lz4

对于 Ubuntu 20.04 及以上版本：

sudo apt-get install -y lz4

4. 解压和刷写​

步骤1： 在Ubuntu主机PC上解压下载的镜像文件：

cd <镜像路径>
sudo tar xpf  mfi_xxxx.tar.gz
# 例如:
# sudo tar xpf mfi_recomputer-super-orin-nx-16g-j401-6.2-36.4.3-2025-05-22.tar

步骤2： 执行以下命令将JetPack系统刷写到NVMe SSD：

cd mfi_xxxx
# 例如:
# cd mfi_recomputer-orin-super-j401
sudo ./tools/kernel_flash/l4t_initrd_flash.sh --flash-only --massflash 1 --network usb0 --showlogs

刷写成功

刷写命令可能运行2-10分钟。

步骤3： 使用板子上的HDMI连接器将Jetson连接到显示器，并完成初始配置设置：

请根据您的需要完成系统配置。

步骤4（可选）： 安装Nvidia Jetpack SDK

请在Jetson设备上打开终端并执行以下命令：

sudo apt update
sudo apt install nvidia-jetpack
