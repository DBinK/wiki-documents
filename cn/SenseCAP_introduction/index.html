SenseCAP 生态系统介绍

SenseCAP 产品线提供了一系列满足不同用户需求的产品，从爱好者到工业用户，涵盖了数字化周围世界的全面解决方案。

从传感器到网关，用户可以构建和定制自己的解决方案，用于监控和控制环境的各个方面。该产品线还包括可大规模部署的工业级设备，提供先进的功能和强大的性能。

此外，SenseCAP 产品线还提供了一系列软件、云服务和 API，使用户能够实时收集、存储和分析数据。硬件、软件和云服务的结合使用户能够快速响应环境变化，并做出基于数据的决策。

野外物联网 (Wild IoT)​

野外物联网是指在自然环境中部署传感器网络，以实时监测和收集各种环境数据。这些数据包括温度、湿度、气压、光照强度、土壤湿度等，有助于科学研究、生态保护和资源管理。

为什么需要工业传感器？​

  1. 耐用性和可靠性：户外环境复杂多变。工业传感器具有耐高温、高湿和抗腐蚀的特点，能够在恶劣条件下长期稳定运行。
  2. 高精度数据采集：科学研究和环境监测需要高精度数据。工业传感器的高精度和稳定性满足了这些需求。
  3. 低功耗和长电池寿命：在野外供电可能是一个挑战。工业传感器通常设计为低功耗设备，能够长时间运行，减少维护和更换电池的频率。

它们如何工作？​

  1. 数据采集：工业传感器安装在户外环境中，实时采集温度、湿度、气压等数据。
  2. 数据传输：采集到的数据通过低功耗广域网 (LPWAN) 技术（如 LoRaWAN）传输到网关。
  3. 数据处理和存储：网关将数据发送到云平台进行处理、存储和分析。
  4. 数据可视化和应用：用户可以通过云平台上的应用程序或仪表板实时查看数据，辅助分析和决策。

软件服务​

SenseCAP 门户​

SenseCAP 门户旨在帮助客户管理设备、数据和访问密钥。在创建自己的账户后，您可以将所有设备绑定到该门户。要了解有关门户的快速入门和指南，请访问 SenseCAP 文档中心 – 门户。

SenseCAP Mate APP​

SenseCAP Mate APP 是一款功能强大的应用程序，用于数据可视化和远程设备管理。

  • 节省时间 - 提供扫描即用的体验，使用户能够在4个步骤内完成整个配置
  • 适合技术背景较少或没有技术背景的人轻松开始使用传感器数据
  • 在简洁的用户界面上获取和查看数据
  • 设置时间间隔：提高电池效率
  • 设置阈值：专注于需要采取行动的数据 - 即将推出
  • 如果数据超出安全范围发送警报 - 即将推出

SenseCAP AI​

SenseCAP AI 是一款基于人工智能的解决方案，帮助您充分利用传感器数据并释放其全部潜力。通过将您的 SenseCAP 传感器连接到 SenseCAP 平台，您可以轻松收集和分析环境因素的数据，例如温度、湿度、光照和空气质量。同时，我们强大的人工智能算法会利用这些数据为您提供可操作的洞察和建议，帮助您优化运营、降低成本并提高效率。

无论您是想监测空气质量、优化作物生长还是提高效率，SenseCAP AI 都拥有您成功所需的工具。SenseCAP AI 目前已在 SenseCAP 门户 和 SenseCAP Mate App 上发布，用户可以随时使用。通过我们易于使用的平台和应用程序，您可以快速连接传感器，并在几分钟内开始接收有价值的洞察。

SenseCAP API​

通过使用 SenseCAP 应用程序编程接口，您可以管理自己的 SenseCAP 设备和数据，以满足您的特定需求。您可以灵活应用以下三种类型的 API 方法：

  • 使用 HTTP API，您可以管理 LoRa 和 NB-IoT 设备，获取原始数据或历史数据。
  • 使用 MQTT API，您可以通过 MQTT 协议订阅传感器的实时测量数据。
  • 使用 WebSocket API，您可以通过 WebSocket 协议获取传感器的实时测量数据。

要了解更多关于 SenseCAP API 的指南和参考，请访问 SenseCAP 文档中心 – API。

应用场景​

5 分钟开发一个工业级 LoRaWAN 传感器​

让我们快速构建一个工业级 LoRaWAN 无线传感器，用于直接商业用途，仅需 5 分钟。

在为商业数据采集项目进行原型开发时，通常需要耗费大量时间和成本。例如，我们需要为一个农业项目制作一个无线 pH 传感器。我们需要：1）找到开发板和传感器探头；2）编写代码；3）3D 打印外壳；4）最终组装测试。完成原型可能需要数天甚至数周的时间。

如今，我们可以使用无线 LoRa 数据采集器，通过蓝牙设置传感器连接到应用程序，并在五分钟内构建一个产品，直接应用于商业项目。
