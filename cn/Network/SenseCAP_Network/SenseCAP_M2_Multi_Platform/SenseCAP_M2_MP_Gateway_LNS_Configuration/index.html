SenseCAP M2 多平台网关 LNS 配置

网关配置​

通过 Web UI 配置网关，请参考 快速入门 登录 Luci。

信道计划设置​

导航到 LoRa > Channel Plan

选择区域和频率计划。

设置完成后，点击 Save&Apply。

本地网络服务器配置​

导航到 LoRa > LoRa Network

将模式设置为 Local Network Server，添加您的 MQTT 信息（Broker Host/Port/User/Password），其他参数可保持默认值。

点击 Save&Apply 应用您的设置。

注意

启动过程大约需要 1 分钟，然后您可以访问 GUI 配置。

ChirpStack GUI 配置​

通过 http://localhost:8080 登录 ChirpStack GUI。

默认账号和密码：admin。

然后您将看到仪表板页面。

检查区域​

导航到 Network Server > Regions。

应该有一个区域 ID，点击它并确认信息，确保与您之前步骤中的设置一致。

添加设备配置文件​

导航到 Tenant > Device Profiles，然后点击 Add Profile。

MAC 版本：LoRaWAN 1.0.3

区域参数版本：A

ADR 算法：默认 ADR 算法（仅 LoRa）

预期上行间隔：自定义，默认 3600 秒

导航到 Codec，选择 JavaScript functions，复制 SenseCAP Decoder for TTN 并提交。

添加网关​

导航到 Gateway，然后点击 Add Gateway。

定义名称和网关 ID（您可以点击随机生成 ID），然后提交。

添加设备​

导航到 Tenant > Application，然后点击 Add Application。

命名您的应用程序并提交。

导航到您的应用程序，然后点击 Add device。

粘贴您的设备 EUI，并选择我们之前添加的设备配置文件，然后提交。

粘贴应用程序密钥并点击提交。

检查设备状态​

检查设备的 Events，当设备加入网络时，您将收到加入数据包。

您还可以检查数据包详情。

集成​

本章节适用于云服务开发，以下指南供参考。

MQTT​

主题​

MQTT 集成会公开所有事件类型文档中记录的事件。

默认事件主题为：

application/APPLICATION_ID/device/DEV_EUI/event/EVENT

查看 事件类型 了解更多详情。

您可以在应用程序标签中找到应用程序 ID：

  • 事件类型
事件类型描述
up上行事件
status信号强度和电池状态
join设备加入事件
ack确认下行 (n)ack
txack下行传输 ack
log日志（或错误）事件
location位置事件
integration集成事件
注意

+ 表示接收所有消息

示例：

  • 接收某个网关下所有设备的上行消息：
gateway/<GATEWAY_EUI>/device/+/event/up
  • 接收某个应用程序下所有设备的所有消息：
application/+/device/+/event/+
  • 接收所有网关下所有设备的消息：
gateway/+/device/+/event/+

您可以检查 gatewayid 来区分网关。

负载​

当 object.valid 为 true 时，表示数据分析成功，您可以遍历 object.messages 并提取所需的数据类型。

  1. SenseCAP LoRaWAN S210X 传感器的上行事件负载示例说明：

  • upload_battery：电池
  • upload_interval：上传间隔，单位：秒
  • upload_version：硬件/固件版本
  • report_telemetry：测量值

‘report_telemetry’ 消息中的 measurementId 请查看 SenseCAP Measurement ID 了解更多详情。

  1. SenseCAP 数据记录仪的上行事件负载示例说明：

‘report_telemetry’ 消息中的 measurementId 请查看 SenseCAP Measurement ID 了解更多详情。

HTTP​

点击 HTTP 标签中的 + 添加新的 HTTP 集成。

LNS 将以 POST 的形式发送消息到配置的 URL。

提交您的 URL 信息。

注意

仅支持 http，不支持 https。

HTTP 集成将向配置的事件端点或端点（可以配置多个 URL，使用逗号分隔）发送 POST 请求。事件 URL 查询参数指示事件的类型。

HTTP 集成会公开所有事件类型，具体请参考 事件类型。

示例：

main.py
from http.server import HTTPServer, BaseHTTPRequestHandler 

from urllib.parse import urlparse, parse_qs 

from chirpstack_api import integration 

from google.protobuf.json_format import Parse 

class Handler(BaseHTTPRequestHandler): 

# True - JSON 序列化器 
# False - Protobuf 序列化器（二进制） 
json = False 

def do_POST(self): 

self.send_response(200) 

self.end_headers() 

query_args = parse_qs(urlparse(self.path).query) 

content_len = int(self.headers.get('Content-Length', 0)) 

body = self.rfile.read(content_len) 

if query_args["event"][0] == "up": 

self.up(body) 

elif query_args["event"][0] == "join": 

self.join(body) 

else:

print("事件 %s 的处理程序未实现" % query_args["event"][0]) 

def up(self, body): 

up = self.unmarshal(body, integration.UplinkEvent()) 

print("收到来自设备 %s 的上行消息，负载为：%s" % (up.device_info.dev_eui, up.data.hex())) 

def join(self, body): 

join = self.unmarshal(body, integration.JoinEvent()) 

print("设备 %s 加入，DevAddr 为：%s" % (join.device_info.dev_eui, join.dev_addr)) 

def unmarshal(self, body, pl): 

if self.json: 

return Parse(body, pl) 

pl.ParseFromString(body) 

return pl 

httpd = HTTPServer(('', 8090), Handler) 

httpd.serve_forever()

下行​

下行消息：

info

建议将下行消息标记为保留，这样命令不会被重复执行。

默认主题为：application/APPLICATION_ID/device/DEV_EUI/command/down

command：请查看 设备用户手册 中的下行命令了解更多详情。

主题application/APPLICATION_ID/device/DEV_EUI/command/down
devEUI设备 EUI
confirmedtrue/false（是否必须作为确认数据下行发送）
fPort使用的 FPort（必须 > 0）
database64 编码数据（明文，将由 ChirpStack 加密）

示例：

  1. 重启 SenseCAP S210x LoRaWAN 传感器：

主题：

application/dbf6****6c92/device/2CF7F1C2****/command/down

Json：

{

"devEui":"2CF7F1C2****", 

"confirmed":true, 

"fPort":2, 

"data":"AMgAAAAAACsm" 

}
  1. 将 SenseCAP S210x LoRaWAN 传感器的上传间隔设置为 1 分钟：

主题：

application/dbf6\*\*\*\*6c92/device/2CF7F1C2\*\*\*/command/down

Json：

{

"devEui":"2CF7F1C2\*\*\*", 

"confirmed":true, 

"fPort":2, 

"data":"AIkAESIBAJBQ" 

}
